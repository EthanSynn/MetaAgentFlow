# 阻断报警卡模板 (Red Flag Circuit Breaker)

> **核心机制**：赋予大语言模型“主动举手说不知道/停止猜解”的最高豁免权。
> 当子 Agent 遭遇核心数据缺失、逻辑不可调和、依赖环境报错或假设前提被推翻时，**严禁盲目循环重试浪费 Token，严禁擅自脑补幻觉！**
> 必须立即停止生成，并在聊天窗口或黑板输出本报警卡。

---

```markdown
🚩 【BLOCKED / 阻断报警卡】
- **任务编号**：[今日认领编号，例：1105-调研-01]
- **致命阻断原因**：[用 1~2 句话客观说明阻塞根因，绝不废话]
- **影响范围**：[指出导致哪一部分产物无法产出或逻辑卡住]
- **待决事项 (Decision Required)**：[向人类指挥官或主控总台请示决策：方案 A 还是方案 B]
```

---

## 示例 (Example)

```markdown
🚩 【BLOCKED / 阻断报警卡】
- **任务编号**：1105-数据-01
- **致命阻断原因**：数据集中缺少 2024 年度研发投入指标字段，无法拟合指定回归模型。
- **影响范围**：无法生成 Table 3 假设验证结果。
- **待决事项**：
  - 选项 A：使用 CSMAR 备选代理变量 `RD_Ratio` 替代；
  - 选项 B：暂退回到前序样本期 (2018-2023) 先跑基准检验。
```
