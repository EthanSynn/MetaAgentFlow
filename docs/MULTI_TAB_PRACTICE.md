# 浏览器多标签页协作与物理级防降智技巧 (Multi-Tab Practice)

> 无论你使用的是 Chrome, Edge, Safari 还是 Arc，标签页都是最廉价、最高效的“物理隔离容器”。

---

## 1. 黄金三标签页配置 (Golden 3-Tab Setup)

日常开展复杂工作流时，推荐在桌面端常驻以下三类窗口：

| 标签页 | 角色 | 推荐模型 | 核心职责 |
| :--- | :--- | :--- | :--- |
| **Tab 1: 规划总台** | Meta-Orchestrator | DeepSeek-R1 / Claude 3.5 Sonnet / 豆包深度思考 | 输入一句话愿景，获取拆解卡片与全局进度盘点 |
| **Tab 2: 专业执行** | Domain Agent | Claude 3.5 / GPT-4o / Qwen-2.5-Max | 粘贴派工卡，专注于代码、文档、设计提示词产出 |
| **Tab 3: 严格质检** | Audit Agent | 高判别力模型 (如 DeepSeek-R1 / Sonnet) | 挑刺、查重、语法校验与一致性审核 |

---

## 2. 快捷键与会话操作习惯

- **新建标签页**：`Cmd + T` (macOS) / `Ctrl + T` (Windows) —— 产生新任务时毫不犹豫开启新会话。
- **任务完成即关闭**：`Cmd + W` (macOS) / `Ctrl + W` (Windows) —— 子 Agent 将成果追加写入黑板后，直接关闭该标签页，不留任何心智负担。
- **分屏比对**：使用操作系统分屏（macOS Tile Window / Windows Snap），左侧为主控总台与黑板，右侧为执行子标签页。

---

## 3. 防降智的三大纪律

1. **绝对禁止在单一会话里做“全流程大包大揽”**：当发现一个对话已经聊了 15 轮以上，且生成速度明显变慢时，立即执行收尾，把结论拷贝到黑板，在新标签页重新开始。
2. **严防“提示词污染”**：不要把前序会话报错的 100 行调试日志原封不动喂给下游会话，只提取提炼后的核心结论。
3. **黑板即唯一交接点**：任何跨环节的数据传递，必须落盘为文档或黑板文字，严禁依赖模型自身的“长期会话记忆”。
