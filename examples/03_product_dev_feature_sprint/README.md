# 示例 3：敏捷研发特性冲刺流水线 (Product Dev Sprint)

> **目标**：从单句产品想法到高保真架构设计、接口实现与单元测试覆盖。

---

## 节点分工与流转

1. **节点 1：产品架构师 Agent (`1105-产品-01`)**
   - 职能：输出模块级 PRD，包含用户故事、边缘情况（Edge Cases）与接口契约（Interface Contract）。
   - 归宿：写入黑板。

2. **节点 2：核心研发 Agent (`1105-研发-01`)**
   - 依赖清单：仅读取节点 1 的接口契约。
   - 职能：根据接口契约实现模块代码，遵循 Clean Code 原则。
   - 遇到第三方库冲突或不兼容：立即触发【🚩 阻断报警卡】。

3. **节点 3：QA 自动化测试 Agent (`1105-测试-01`)**
   - 依赖清单：接口契约 + 研发产物。
   - 职能：针对正常流与异常流编写测试用例，覆盖率目标 90%+。
