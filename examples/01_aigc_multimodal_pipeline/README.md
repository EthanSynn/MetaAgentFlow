# 示例 1：AIGC 跨模态视频工业化流水线 (AIGC Pipeline)

> **目标**：在 3 个独立标签页内，将一句话灵感转化为工业级分镜台本与高精绘图/视频生成提示词。

---

## 协同拓扑设计

```text
[人类需求] ──▶ [Tab 1: 概念与剧本 Agent] ──▶ 写入黑板分镜
                                                    │
                                     ┌──────────────┘
                                     ▼
                     [Tab 2: 视觉提示词工程 Agent] ──▶ 写入 Midjourney/可灵 Prompt
                                                    │
                                     ┌──────────────┘
                                     ▼
                     [Tab 3: 严格审美与一致性 Audit Agent] ──▶ 最终成品输出
```

---

## 实操步骤

### 步骤 1：主控派工 (Tab 0)
在主控窗口输入：
> “我要制作一段关于‘赛博朋克深海科研基地’的 60 秒概念短片，请帮我生成 3 节点流水线派工卡。”

### 步骤 2：生成分镜 (Tab 1 · `1105-剧本-01`)
- 新建标签页，粘贴派工卡 1。
- 产出包含景别、运镜方式、环境音效与角色动作的 6 个分镜。
- 发出口令“存档”，Agent 自动将分镜写入共享黑板 `DAILY_HANDOVER.md`。

### 步骤 3：提示词工程 (Tab 2 · `1105-提示词-01`)
- 新建标签页，粘贴派工卡 2（严格仅依赖黑板中的分镜段落）。
- 输出中英对照的 Midjourney v6 参数提示词（包含 `--ar 16:9 --v 6.0 --style raw`）与可灵运动描述。
- 存档写入黑板。

### 步骤 4：审美一致性审查 (Tab 3 · `1105-审查-01`)
- 新建标签页，读取黑板产物与禁忌清单（杜绝塑料质感、保证冷调工业蓝灰基调一致）。
- 剔除劣质词，输出最终可直接批量导入生成器的成品清单。
