# 示例 2：学术实证研究与文献矩阵编排流 (Academic Pipeline)

> **目标**：不写一行 Python 爬虫，依靠 Chat-Native 协同协议在 3 个标签页内完成顶刊文献综述矩阵、实证模型假说推演与审稿人视角对抗审查。

---

## 节点分工与 Manifest 清单

1. **节点 1：文献综述与理论机制 Agent (`1105-理论-01`)**
   - 依赖清单：选题关键词 + 核心参考理论（如企业脱耦理论 / 资源基础观）。
   - 产出：核心机制假说逻辑链与 10 篇关键顶刊文献比对矩阵。
   - 交付：写入黑板【待处理活跃区】。

2. **节点 2：变量设计与计量模型 Agent (`1105-计量-01`)**
   - 依赖清单：仅读取黑板节点 1 的假说结论。
   - 产出：双向固定效应回归方程 LaTeX、被解释变量/核心解释变量/控制变量操作化定义表格。
   - 交付：写入黑板【待处理活跃区】。

3. **节点 3：匿名审稿人对抗审查 Agent (`1105-审查-01`)**
   - 依赖清单：黑板前序汇总。
   - 职能：扮演苛刻的匿名审稿专家（Reviewer 2），专攻内生性问题（遗漏变量、反向因果）、测量误差与稳健性检验缺陷，输出修改备忘录。
